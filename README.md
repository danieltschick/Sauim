# Sauim
Editor de textos

#Autor:
Daniel Tschick Tomaz

#Objetivo:
Criar uma ferramenta de edição de textos brasileira independente. A criação de código está tão acessível e rápida no ano de 2026, que não acredito que faça mais sentido depender de empresas de fora do país. Este é um tipo de produto que o Brasil já é capaz de desenvolver internamente. Podemos fazer que o dinheiro enviado para fora através de licenças pagas ou através do compartilhamento de dados pessoais (no caso de serviços gratuitos) pode continuar circulando internamente, fortalecendo a economia interna.

Por este motivo também, decidi criar a ferramenta como um arquivo executável para ficar no HD computador, tornando o usuário dono do seu arquivo pelo tempo que desejar e não depender de um SSAS ou hospedado em nuvem correndo o risco de ser encerrado contra a vontade do usuário.

Este pontapé inicial não tem o objetivo de ser completo nem perfeito, mas sim, lançar uma versão minimamente capaz do básico para uso doméstico ou por estudantes. Pode e deve ser melhorado por quem assim desejar.

#Linguagem:
Python. Desenvolvido com o auxílio de ferramentas de IA para geração de código.

# Origem do nome
Sauim é a palavra em Tupi Guarani para "Sagui" (fonte: https://biblioteca.funai.gov.br/media/pdf/Folheto43/FO-CX-43-2739-2000.pdf)
Sagui é uma família de macacos que ocorre na América do Sul. (https://pt.wikipedia.org/wiki/Calitriqu%C3%ADdeos)
