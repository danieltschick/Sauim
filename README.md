# Sauim
Editor de textos

#Autor:
Daniel Tschick Tomaz

#Objetivo:
Este pontapé inicial não tem o objetivo de ser completo nem perfeito, mas sim, lançar uma versão minimamente capaz do básico para uso doméstico ou por estudantes. Pode e deve ser melhorado por quem assim desejar.

Decidi criar a ferramenta como um arquivo executável para ficar no HD computador, tornando o usuário dono do seu arquivo pelo tempo que desejar ao invés um SaaS. Um software como serviço cria uma dependência de assinatura, e no momento em que o serviço encerrar (por sua vontade ou contra ela) você perde a capacidade de ler os seus arquivos.

O objetivo principal é iniciar o desenvolvimento de uma ferramenta de edição de textos brasileira independente. A criação de código está tão acessível e rápida no ano de 2026, que não acredito que faça mais sentido depender de empresas de fora do país para um serviço tão básico. Este é um tipo de produto que o Brasil já é capaz de desenvolver internamente. Podemos fazer que o dinheiro enviado para fora através de licenças pagas ou através do compartilhamento de dados pessoais (no caso de serviços gratuitos) pode continuar circulando internamente, fortalecendo a economia interna.

#Linguagem:
Python. Desenvolvido com o auxílio de ferramentas de IA para geração de código.

# Origem do nome
Sauim é a palavra em Tupi Guarani para "Sagui" (fonte: https://biblioteca.funai.gov.br/media/pdf/Folheto43/FO-CX-43-2739-2000.pdf)
Sagui é uma família de macacos que ocorre na América do Sul. (https://pt.wikipedia.org/wiki/Calitriqu%C3%ADdeos)
